# Шаблон сайта заказа для шашлычной («Угли»)

Обезличенный шаблон сайта с меню, корзиной и оформлением заказа. Название по умолчанию — «ВАШЕ ЗАВЕДЕНИЕ».

## Как показывать владельцу
Откройте ссылку с `?demo=1` (например `.../index.html?demo=1`) — появится кнопка «🎨 Примерка бренда»: прямо на встрече вписываете название, адрес, цвет и логотип заведения.

## Как настроить под клиента
Всё в начале `<script>` в `index.html`:
- `SITE_CONFIG` — название, телефон, адрес, часы работы, доставка, скидка за самовывоз, цвет;
- `MENU_ITEMS` — блюда, граммовки, цены, фото;
- `orderEndpoint` — адрес серверной функции, которая шлёт заказы в Telegram. Пока он пустой, сайт работает в демо-режиме (заказ показывается как пример сообщения в Telegram и никуда не уходит).

## Хостинг
GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.
`robots.txt` и `noindex` закрывают демо от поисковиков; уберите их, когда сайт станет боевым.
